Sales Performance Dashboard

Project Overview

An interactive Power BI dashboard designed to analyze sales performance, monitor revenue trends, evaluate product performance, and explore customer insights.

Tools & Technologies

* Microsoft Power BI
* Power Query
* DAX (Data Analysis Expressions)
* Data Cleaning & Transformation
* Data Modeling & Relationships
* Data Visualization
* Data Validation

Key Features

* Sales KPIs: Total Orders, Customers, Products, and Revenue.
* Revenue analysis over time.
* Top products by quantity and revenue.
* Revenue breakdown by product category.
* Interactive Category and Date filters.
* Data quality and relationship validation.

Project Purpose

To transform sales data into meaningful insights through interactive visualizations and data analysis.
